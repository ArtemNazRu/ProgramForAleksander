# Финансовый путь — приложение для Android

Автономное приложение: уроки, задания, книжная полка и звёзды работают без интернета,
прогресс хранится на телефоне. Интернет нужен только для статей из «Дополнительного чтения».

## Как получить APK без программирования (через GitHub, бесплатно)

1. Зарегистрируйтесь на github.com.
2. Нажмите «+» вверху → **New repository**. Название — `finpath`, отметьте **Private**, нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**.
   Распакуйте архив и перетащите в окно браузера **всё содержимое** папки `finpath-android`
   (папки `app`, `.github` и файлы `build.gradle`, `settings.gradle`, `gradle.properties`, `README.md`).
   Нажмите **Commit changes**.
4. Проверьте, что папка `.github` загрузилась (на Mac и в некоторых проводниках она скрыта).
   Если её нет: **Add file → Create new file**, в имени файла напишите
   `.github/workflows/build.yml`, вставьте содержимое файла `build.yml` из архива и нажмите **Commit changes**.
5. Откройте вкладку **Actions**. Сборка «Собрать APK» запустится сама (если нет — выберите её и нажмите **Run workflow**).
   Через 3–5 минут появится зелёная галочка.
6. Откройте завершённую сборку, внизу в разделе **Artifacts** скачайте **FinPath-apk**.
   Это zip-архив, внутри — файл `FinPath.apk`.

## Как установить на телефон

1. Перешлите `FinPath.apk` на телефон (Telegram «Избранное», почта, кабель).
2. Откройте файл. Android попросит разрешить установку из этого источника — разрешите.
3. Если Play Защита предупредит о неизвестном разработчике — «Подробнее» → «Всё равно установить».
   Предупреждение появляется у любого приложения не из Google Play.

## Как собрать в Android Studio (альтернатива)

File → Open → папка `finpath-android` → дождаться синхронизации → Build → Build APK(s).

## Как обновлять

Содержимое приложения — файл `app/src/main/assets/index.html`. После его изменения
поднимите `versionCode` в `app/build.gradle` (1 → 2), загрузите файлы в репозиторий — GitHub соберёт новый APK.
Установка поверх старой версии сохраняет звёзды. Удаление приложения стирает прогресс.

## Что внутри

- `app/src/main/assets/index.html` — само приложение (уроки, задания, звёзды)
- `app/src/main/assets/fonts/` — шрифты Unbounded и Golos Text (лицензия SIL OFL)
- `app/src/main/java/.../MainActivity.java` — оболочка Android: показывает страницу, кнопка «Назад», ссылки во внешнем браузере
- `.github/workflows/build.yml` — автоматическая сборка APK на GitHub
